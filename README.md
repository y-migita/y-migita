## 何をやってる人か
株式会社Andecoでエンジニアとして働いています。
デザイン畑の出身で、技術領域を横断しながら
課題に対して最適な解決手段を探すのが好きです。

## 扱ってきた領域
- **Webフロントエンド**: Typescript / React / Next.js / Tailwind 等を使ったUI実装およびそのデザイン
- **Backend**: Node.js / Bun(Elysia) / Docker / Python / AWS / Cloudflare
- **IoT/ハードウェア**: 通信(BLE・LoraWAN・RS485等) / マイコン(Arduino・ESP32・M5Stack等) / 設計(Fusion360・EasyEDA等)
- **Native**: React Native・Expo / Swift / Dart・Flutter 等を使ったアプリの開発
- **3D/XR**: Web上の3D表現(WebGL・Three.js等) / BIM/IFCの可視化 / Unity・UE等でのアプリ開発
- **LLM**: AI OCR / RAG・エージェントのPoCにおける開発
